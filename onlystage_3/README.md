# Campus Run — Graduation Run

เกมแพลตฟอร์ม 2 มิติที่ให้ผู้เล่นสวมชุดครุย วิ่งข้ามตึกในมหาวิทยาลัย หลบสัตว์ และหนีนักข่าวให้ทันพิธีรับปริญญา เล่นได้ทั้งบนคีย์บอร์ดและบอร์ด Digilent Nexys 4 DDR

## เริ่มเล่นบน Windows

1. เปิดโฟลเดอร์ที่มี `main.py` ใน VS Code ถ้าใช้ `CampusRun_Code.zip` ให้แตกลงในโฟลเดอร์เกมเดิมและรวมโฟลเดอร์ `assets/` เข้าด้วยกัน เกมใช้ภาพตัวละคร สัตว์ ไอคอน และ tileset จากโปรเจกต์เดิมด้วย
2. เปิด Terminal ในโฟลเดอร์นั้น แล้วรันสองคำสั่งนี้ด้วย Python ที่มี Tkinter

```powershell
py -m pip install --upgrade Pillow
py main.py
```

3. เมื่อเห็นหน้า **HOW TO PLAY** กด **Space** หรือ **Enter** เพื่อเริ่มด่าน 1 เกมจะพาไปด่านถัดไปเองเมื่อผ่านเส้นชัย

## ปุ่มควบคุม

| Action | Keyboard | Nexys 4 DDR |
| --- | --- | --- |
| Move left / right | A / D หรือ ← / → | BTNL / BTNR |
| Jump | W, ↑ หรือ Space | BTNU |
| Double jump | ปล่อยแล้วกดปุ่มกระโดดอีกครั้งกลางอากาศ | ปล่อยแล้วกด BTNU อีกครั้ง |
| Use skill | E | BTNC |
| Start / Pause / Resume | Enter | BTND |

**เล่นด้วยบอร์ด** ติดตั้ง `pyserial` ด้วย `py -m pip install pyserial` แล้วเสียบบอร์ดที่ลงโปรแกรมควบคุมของเกมไว้ผ่าน USB เลือกพอร์ต COM ในหน้าต่างเกมแล้วกด **Connect board** เกมสื่อสารที่ 115200 baud และส่งจำนวนวินาทีที่เหลือของสกิลไปแสดงบนจอ 7-segment

## เส้นทางทั้ง 3 ด่าน

| ด่าน | เส้นทาง | วิธีผ่าน |
| --- | --- | --- |
| 1 | S6 → S4 | กระโดดข้ามสิ่งกีดขวาง แล้วเดินเข้าตึกแดง S4 |
| 2 | S4 → CB2 | กระโดดชนใต้กล่องปริศนาที่ x = 240 แล้วเดินเก็บชานม ตัวละครจะเปลี่ยนเป็นร่างทองและขยายขึ้น 8% นาน 3 วินาที เมื่อกลับขนาดเดิมแล้วก็ยังเดินเข้า CB2 ในร่างทองได้ |
| 3 | N17 → N16 | ใช้แท่นไม้ข้ามช่องเหว แล้วเดินเข้า N16 เพื่อจบเกมและรับคำยินดีในวันรับปริญญา |

แต่ละด่านยาว 250 ช่อง สูง 11 ช่อง กล้องแสดงครั้งละ 20 × 11 ช่อง แถบด้านล่างบอกระยะทางเป็นเปอร์เซ็นต์ ผู้เล่นมีเวลา 120 วินาทีต่อรอบ ถ้าตกน้ำ ตกเหว หรือหมดเวลา จะกลับจุดเกิดของด่านปัจจุบันพร้อมเวลาและสกิลเต็ม กด **Retry stage** เพื่อเริ่มด่านนั้นใหม่ หรือ **New game** เพื่อกลับด่าน 1

## นักข่าวและสกิล

ชนสัตว์ครั้งแรก นักข่าวจะเริ่มวิ่งตาม ถ้าชนอีกครั้งระหว่างถูกตาม ตัวละครจะหยุดสัมภาษณ์ 5 วินาที โดยมีคำถามสุ่ม 2 ข้อ เวลาของด่านยังเดินระหว่างสัมภาษณ์

- **Cloak · ด่าน 1–2** กดตอนนักข่าวตามเพื่อล่องหน 5 วินาที นักข่าวจะขึ้นเครื่องหมาย `?` และตามต่ออีก 0.6 วินาที ก่อนถอยกลับเป็นเวลา 2 วินาที
- **Phase · ด่าน 3** กดเพื่อขยายร่างเป็น 1.5 เท่าของร่างปกติในด่านนี้ และเดินผ่านสัตว์ได้ 5 วินาที ถ้ามีนักข่าวตามอยู่ก่อนกด นักข่าวจะยังตามต่อ

ใช้สกิลได้หนึ่งครั้งต่อการเล่นด่านแต่ละรอบ ดูสถานะที่มุมขวาบน **READY** คือพร้อมใช้ ตัวเลขคือวินาทีที่เหลือ และ **USED** คือใช้ไปแล้ว

## แก้เกมตรงไหน

| ต้องการปรับ | ไฟล์และตำแหน่ง |
| --- | --- |
| เวลา ความเร็ว ขนาดสัตว์ ความสูงกระโดด หรือจุดเกิด | `settings.py` เช่น `TIME_LIMIT`, `RUN_SPEED`, `ANIMAL_HEIGHT` และ `SPAWNS` |
| พิกัดสัตว์ ระยะเดิน และจำนวนสัตว์ | `game.py` ใน `first_stage_animals()`, `second_stage_animals()` หรือ `third_stage_animals()` |
| ระยะเวลาตัวใหญ่หลังเก็บชานม | `game.py` ค้นหา `self.tea_growth_until = self.time + 3.0` |
| ผังบล็อก | เปิด `assets/map_1.tmj`, `assets/map_2(1).tmj` หรือ `assets/map_3.tmj` ใน Tiled เก็บ tileset และภาพไว้ตามพาธที่แมพอ้างถึง |
| รูปตัวละคร สัตว์ หรือพื้นหลัง | วางรูปใน `assets/` ใช้ชื่อเดิมหรือเปลี่ยนชื่อใน `settings.py` แล้วปิดเกมและเปิดใหม่ |
| สีเมนู นาฬิกา และกล่องคำถาม | `hud.py` ส่วนข้อความที่นักข่าวสุ่มถามอยู่ที่ `QUESTIONS` ใน `settings.py` |

## ข้ามด่านสำหรับเจ้าของเกม

ถ้ามีไฟล์เสริม `owner_mode.py` ให้วางไว้ข้าง `main.py` แล้วรัน `py owner_mode.py` หน้าต่างจะขึ้นชื่อ **Campus Run | Owner Mode** เลือกด่านจากเมนู **Select stage** หรือกด **F1 / F2 / F3** เพื่อเข้าด่าน 1 / 2 / 3 ตามลำดับ แต่ละครั้งจะเริ่มที่จุดเกิดพร้อมเวลาและสกิลเต็ม
